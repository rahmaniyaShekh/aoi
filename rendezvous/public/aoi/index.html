Listen to a PC

Enter the code shown on the host PC. Audio comes straight from it to you, encrypted.

    To share a Windows 11 PC, install AOI from its GitHub release (repository access needed). In PowerShell:

    gh release download -R rahmaniyaShekh/aoi -p install.ps1 -O - | Out-String | iex

    Then aoi start shows the code, aoi stop ends it. No admin, nothing to set up.
